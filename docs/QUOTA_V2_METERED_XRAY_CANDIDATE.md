# Metered Xray candidate for clean Quota V2 deployment

The installed Quota V2 matrix uses an instrumented Xray built from the immutable upstream revision `a4a3dff5b20c2faae567b742c172c7b95e75c083` and the reviewed Node patch. Ordinary Node bootstrap does not yet provision that executable or the isolated production ingress. Do not enable ordinary issuance by setting the Nexus feature flag alone.

The patched-real-xray job builds a Linux amd64 candidate with Go 1.27.4, CGO disabled and `-trimpath`. It tests those exact bytes for signed admission, per-user VLESS isolation, UDP/XUDP fencing and SIGKILL durability. After the tests it applies the same reviewed patch to a second clean checkout of the pinned upstream commit and rebuilds using a separate build cache. A byte mismatch is a failure; no candidate is uploaded. The candidate artifact contains the executable, its digest, a manifest of immutable source identities and build inputs, and checksums. This is CI evidence, **not** a signature, provenance attestation, installation permission, or final-meter proof.

Next release boundary: bind the exact candidate and its trusted build provenance to the approved Agent release record; provision the measured runtime and ingress from the normal fresh installer, not a test-side helper. Preserve strict-PQ activation, signed cap verification, private runtime fencing, immutable WAL, conservative no-refund accounting, and fail-closed behavior on all unqualified transports or profiles. Qualify real externally reachable VLESS/TLS and other supported production transport profiles, user roster changes, restarts and rollback without staging-only markers. Until then production activation remains unauthorized.
